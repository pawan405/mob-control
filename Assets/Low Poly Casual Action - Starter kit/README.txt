--------------------------------------------------------------------------------
2. MODULAR TRACK GRID & ALIGNMENT GUIDE
--------------------------------------------------------------------------------
All track pieces are modeled with precise meter-based dimensions and exact pivot 
points to allow seamless grid snapping (Hold Ctrl in Unity while moving).

TRACK SPECIFICATIONS:
* Track Width: 10 Meters

1. STRAIGHT TRACK (Length: 20m)
   - To connect the next straight piece, move it exactly +20m forward on the 
     Z or X axis.

--------------------------------------------------------------------------------
3. CHARACTERS & ANIMATIONS
--------------------------------------------------------------------------------
- Rigging: Fully rigged Level 1 Stickman set to Humanoid Avatar type.
- Animation Compatibility: Seamlessly works with Unity Starter Assets, 
  and any standard Humanoid animation packages.
- Setup: Drag and drop the stickman prefab into your scene and assign your 
  Animator Controller.

--------------------------------------------------------------------------------
4. RENDER PIPELINE SUPPORT
--------------------------------------------------------------------------------
By default, materials use Unity's Standard/Mobile shaders. If you are using 
Universal Render Pipeline (URP) or HDRP:
- Go to: Edit -> Render Pipeline -> Universal Render Pipeline -> Upgrade Project Materials
